# Quick Start Guide - New Features

## 🚀 What's New?

Three major improvements to your habit tracker:
1. **Better Routine Display** - Clean, readable, no clutter
2. **Create Habit with Routine** - Optional AI routine during creation
3. **Edit Habit Feature** - Change schedule and settings anytime

---

## ⚡ Quick Start

### 1️⃣ Create a Habit with Routine (NEW)

**Steps:**
1. Go to "➕ Add Habit" page
2. Fill in habit name (e.g., "Morning Meditation")
3. **NEW:** Check ☑️ "💡 Generate AI Routine for this habit"
4. (Optional) Enter prompt: "Give me a beginner-friendly meditation routine"
5. Click "Create Habit"
6. ✅ Done! Habit created with routine

**Result:**
- Habit appears in "All Habits"
- Click 💡 button to view generated routine
- No extra steps needed!

---

### 2️⃣ Edit an Existing Habit (NEW)

**Steps:**
1. Go to "📋 All Habits"
2. Find the habit you want to edit
3. **NEW:** Click ✏️ edit button (next to × delete)
4. Modal opens showing current settings
5. Change schedule, skip days, or duration
6. Click "Save Changes"
7. ✅ Done! Updates immediately

**What You Can Edit:**
- ✅ Skip days per week (0-3)
- ✅ Specific days to skip
- ✅ Minimum duration
- ❌ Habit name (create new instead)

---

### 3️⃣ View Improved Routines

**Steps:**
1. Click 💡 button on any habit
2. **IMPROVED:** Clean, formatted routine appears
3. Scroll through content (smooth scrollbar)
4. Close button always visible

**What's Better:**
- ✅ No repeated symbols (••, --, **)
- ✅ Clear headings and subheadings

- ✅ Better mobile view

## 💡 Tips & Tricks

### Creating with Routines:
- **Blank prompt:** Gets general routine for habit
- **Specific prompt:** Gets tailored advice
- **Examples:**
  - "Give me a morning routine"
  - "How can I stay consistent?"
  - "Tips for beginners"
  - "Weekly schedule that fits a 9-5 job"

### Editing Habits:
- **Can't change name?** That's intentional for data integrity
- **Want different name?** Create new habit instead
- **Changing schedule:** Edit takes effect immediately
- **Skip days:** Pick any days that work for you

### Viewing Routines:
- **Regenerate:** Click 🔄 to create new version
- **Delete:** Click 🗑️ if you don't need it
- **Print/Save:** Copy text to notes app
- **Share:** Screenshot and send to friends

## 🆘 Need Help?

### Common Questions:

**Q: Why can't I rename habits?**
A: Habit names are immutable for data integrity. Create new habit if you need different name.

**Q: Can I edit routine content?**
A: Yes! Click 🔄 Regenerate with new prompt, or delete and create new one.

**Q: Will editing break my streak?**
A: No! Editing settings doesn't affect your completion history or streak.

**Q: Can I edit multiple habits at once?**
A: Not yet - edit one at a time for now.


**Q: What if I accidentally save wrong settings?**
A: Just edit again and fix it. No limit on edits.
